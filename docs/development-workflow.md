# Development Workflow

## Branches
- `main`: Stable integration / production-ready branch.
- `frontend`: All frontend application development.
- `backend`: Backend/API/business logic development.
- `database`: Firebase/Firestore database architecture, rules, indexes, storage rules, and database documentation.

## Branch Rules
- `main`: Stable code only. No direct feature development. Integration branch.
- `frontend`: Frontend code only.
- `backend`: Backend code only.
- `database`: Database configuration and database-related files only.

Do not mix unrelated work between branches.
