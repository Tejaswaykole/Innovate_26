# Project Requirements

## ROLES
1. Participant
2. Judge
3. Admin

*Note: Team Leader is NOT a separate authentication role.*

Team-level roles:
- leader
- member

## TEAM
- **Minimum:** 2 members
- **Maximum:** 6 members
- **At least:** 1 female member compulsory
- **Team leadership:** Permanent
- **Leadership transfer:** Not allowed
- **Team members:** Cannot leave the team
- **Team requests:** A participant can request to join a maximum of 5 teams
- **Team code:** 6-character random code

## PROBLEM STATEMENT
- Open-ended.
- Teams choose their own problem statement.
- **Hardware projects:** Allowed
- **Software projects:** Allowed

## SUBMISSION
- Only Team Leader can submit.

Required:
- Project Title
- Problem Statement
- Project Description
- PPT
- GitHub Repository Link
- Project/Demo Link
- Demo Video

Demo video:
- Required
- Audio: Compulsory
- Screenshots: Allowed

## RECOGNITION
- Top 3 teams
- Participant certificates
- Sponsors: None
- Partners: None

## DATABASE
- Firebase Firestore

## AUTHENTICATION
- Firebase Authentication

## FILE STORAGE
- Firebase Storage
